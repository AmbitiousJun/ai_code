主流程就绪后，按保存顺序检查条件并串行执行。截图条件未匹配时持续轮询，匹配成功才执行；子流程检查点未匹配时让出执行，继续检查其他子流程和最终巡检，随时可以停止。

可以先在 Chrome 中准备触发画面，这些准备动作不记录。确认条件后开始录制后续动作。

使用本机时区，最小精度 1 秒，兼容旧版五段（分钟级）表达式。支持数字、*、范围、列表和步长。每 N 秒/分钟按分钟/小时边界计算。只检查当前时刻，不补跑错过的时刻；同一秒（旧版为同一分钟）每实例最多成功执行一次。动作串行执行，耗时动作可能延迟或错过触发。

03 表单变量 整段 / 片段随机

保持原值，或用模板替换指定字段。例：user_{{digits:6}}@example.com。同一次回放内，同一字段复用生成值；自动恢复时重新生成。

查看模板语法与示例

{{int:1000:9999}} → 4 位随机整数
138{{digits:8}} → 固定前缀 + 8 位随机数字
user_{{letters:6}}_{{instance}} → 随机字母 + 实例编号
{{uuid}} → 随机 UUID
可组合多个片段。随机值不保证唯一，唯一标识优先用 UUID。

04 执行与巡检配置

默认使用固定操作间隔，不重放人工停顿。悬停触发菜单的动作仍保留，拖动手势内部时序仍保留。异步加载请用截图检查点等待。

异常恢复会从头重放整个流程。请确保流程允许重复执行。连续 5 次健康检查后重置恢复计数。图像检查只判断所选画面，不代表业务心跳。

这七项配置用于基础步骤；其余执行与巡检参数继承所属全流程。基础流程单独录制时使用默认浏览器参数。
